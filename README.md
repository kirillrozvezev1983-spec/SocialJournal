# ЧЕРНОВИК — мини-социальная сеть на Django

Учебный проект по заданию «аналог Живого журнала». Используются Django, обычные функции `views.py`, `urls.py`, модели, Django Forms, HTML-шаблоны, CSS в `static` и небольшой JavaScript. API/DRF и сторонние библиотеки не используются.

## Что умеет сайт
- Регистрация с именем, уникальным логином, email, паролем, возрастом, работой и увлечениями.
- Пароли обрабатываются встроенной системой Django, открытым текстом не сохраняются.
- Автоматический вход после регистрации, вход и выход.
- Личный кабинет и стена своих постов; публикация, редактирование и удаление только своих постов.
- Общая лента «Интересное», постраничный вывод, страницы других пользователей.
- Лайки можно ставить и снимать; нельзя лайкать собственные посты; повторные лайки запрещены ограничением базы.
- Тёмная/светлая тема с запоминанием выбора.
- Переключатель языка RU/EN (механизм Django i18n подключён; сами тексты шаблонов сейчас преимущественно на русском).
- Панель администратора Django.

## Запуск в PyCharm на Windows
1. Распакуй архив и открой папку `SocialJournal` в PyCharm.
2. Открой Terminal в PyCharm и выполни команды по очереди:

```powershell
python -m venv venv
.env\Scriptsctivate
pip install -r requirements.txt
python manage.py makemigrations network
python manage.py migrate
python manage.py runserver
```

3. Открой в браузере `http://127.0.0.1:8000/`.
4. Создать администратора можно командой `python manage.py createsuperuser`, после чего панель доступна по адресу `http://127.0.0.1:8000/admin/`.

## Основные адреса
- `/` — главная
- `/interesting/` — общая лента
- `/register/` — регистрация
- `/login/` — вход
- `/cabinet/` — личный кабинет
- `/user/логин/` — комната пользователя

База SQLite создаётся автоматически после `migrate`. Миграцию приложения можно создать командой `python manage.py makemigrations network`.
